# ProyectoFinalDMC

El objetivo principal es analizar los factores que influyen en la renovación de pólizas de seguro (`renewal`) mediante estadística descriptiva, programación orientada a objetos y visualización de datos interactiva.
El proyecto se ejecuta en streamlit, donde se hace una presentación del proyecto, luego en el módulo 1 se pide cargar el dataset y en el módulo 3 se presentan el análisis exploratorio de datos.
